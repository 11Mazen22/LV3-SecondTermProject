# Level 3 Second Term Project

## Machine Learning GitHub Repository Analysis

This project collects repository data from the GitHub API and analyzes it with Pandas, SQLite, SQL, and Matplotlib.

## Files
- `LV3_SecondTermProject_Mazen_STUDENT_ID.ipynb` - main project notebook
- `github_projects.csv` - cleaned dataset created by the notebook
- `github_projects.db` - SQLite database created by the notebook
- `screenshots/` - Git and GitHub evidence screenshots

## Data Source
GitHub REST API repository search:
https://api.github.com/search/repositories?q=machine+learning&sort=stars&order=desc&per_page=100

## Notes
Run the notebook from the first cell so the dataset is collected and prepared before the SQL analysis is run.
